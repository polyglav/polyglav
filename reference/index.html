    • Roles - role catalog, storage, delegation and permission rule
    • API endpoints - HTTP JSON API for polyglav serve
    • Architecture - agent core: the loop, engine, UI sinks, front-ends, extension points
    • Commands & CLI - slash commands and headless CLI flags
    • Configuration - config schema and keys

    • Model Context Protocol - MCP client and server

    • Testing - running the mock test suite, per-file coverage map
    • Tools - tool registry, bundled tools, tool policy, registration metadata
